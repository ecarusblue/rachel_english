# 여러 선생님 쓰기

원장 1명 + 선생님 여러 명이 같은 앱을 쓸 수 있습니다. 선생님은 **자기 담당 학생**의 진도·수업 기록·시험·라이팅·월말평가만 볼 수 있고,
교재와 시험 종류는 모두 함께 쓰고, 시간표는 내 학생만 보입니다. 원장은 전부 볼 수 있습니다.

## 처음 한 번 하는 설정

1. **Supabase SQL Editor**에서 최신 `schema.sql` 전체를 실행합니다. (여러 번 실행해도 안전, 맨 아래 `9. 여러 선생님` 부분이 추가됨)
2. **Cloudflare** > Workers > `rachel-english` > 설정 > 변수 및 비밀 에 **비밀값** `SUPABASE_SERVICE_KEY` 를 추가합니다.
   - Supabase > Project Settings > API 의 **service_role / secret 키**입니다. 이 키는 Worker 서버에서만 쓰이고 브라우저·저장소에는 들어가지 않습니다.
   - 선생님 계정을 만들고 비밀번호 설정 메일을 보내는 데만 사용합니다. (없으면 '선생님 추가'만 안 되고 나머지는 정상)
3. **Supabase > Authentication > URL Configuration** 의 *Redirect URLs* 에 앱 주소(`https://…workers.dev/`)가 들어 있는지 확인합니다.

## 선생님 추가·배정

- 왼쪽 메뉴 **설정 > 선생님 관리** (원장에게만 보임)
  1. **+ 선생님 추가**: 이름·이메일 입력 → 그 주소로 '비밀번호 재설정' 메일이 갑니다. 선생님이 링크에서 비밀번호를 정하면 사용 시작.
  2. **권한**: 타임 추가·삭제·시간 변경 / 사용 중인 교재 삭제 / 새 학생 등록·퇴원 처리. (내 학생 기록, 시간표 보기, 교재 추가·수정은 항상 가능)
  3. **학생 배정**: 학생마다 담당 선생님 한 명. 담당이 없는 학생은 원장 담당입니다.
  4. **이용 중지**: 로그인만 막고 데이터는 그대로 둡니다. 언제든 '다시 사용'.

## 알아둘 점

- 모든 데이터의 주인(owner)은 계속 원장 계정입니다. 기존 데이터를 옮길 필요가 없습니다.
- 담당을 바꾸면 기록은 학생에게 그대로 따라가고, 이전 선생님 화면에서는 그 학생이 사라집니다.
- 시간표는 모든 선생님이 같은 타임(이름·시간)을 공유합니다. 선생님 화면에는 내 학생만 나오고, 저장해도 다른 선생님 학생은 그대로 보존됩니다.
- Claude 예약 작업(API 토큰)은 원장 권한이라 전체 학생을 대상으로 동작합니다.
- 교재 수정 이력(누가 언제 무엇을)은 교재 수정 창에서 볼 수 있습니다.
