# 4. 교재와 진도

교재는 **원장과 모든 선생님이 함께 쓰는 목록**입니다. 먼저 교재를 만들고, 학생에게 **배정**하면 그 학생의 진도가 관리됩니다.

## 4-1. 교재 만들기

**메뉴 위치:** 왼쪽 메뉴 아래 **설정 → 교재 관리**

1. **교재 관리** 창이 열리면 교재 목록이 나옵니다. 위쪽 검색칸에 교재 이름을 넣어 찾을 수 있습니다.
2. **+ 교재 추가**를 누릅니다. (검색한 이름의 교재가 없으면 "'○○' 교재 추가" 링크도 나옵니다)
3. 입력합니다.

| 항목 | 설명 |
|---|---|
| 교재명 | 필수 |
| 구조 | **flat**: 단원이 1, 2, 3… 한 줄로 이어지는 교재. **tree**: 큰 항목 아래 작은 항목이 있는 교재 |
| 전체 단원 수 | flat 구조일 때 마지막 단원 번호 (예: 20) |
| 단위 이름 | 단원을 부르는 말 (Unit, Lesson, Day 등). 화면에 "Unit 7"처럼 표시됩니다 |
| 텍스트로 편집 | tree 구조일 때 한 줄에 항목 하나씩 적습니다. **앞에 공백을 넣으면 위 항목의 하위 항목**이 됩니다 |

📷 (교재 추가 창)

**tree 구조 입력 예시**

```
Chapter 1
 Part A
 Part B
Chapter 2
 Part A
 Part B
```

진도는 내부적으로 항상 **누적 번호**로 관리되고, 화면에서는 "Chapter 1 › Part B"처럼 보입니다.

### 교재 수정·삭제

- 목록에서 교재 줄의 **수정**을 누르면 같은 창이 열립니다. 이름과 단원 수를 고칠 수 있습니다.
- 교재를 쓰는 학생 수가 줄에 **"○명 사용"** 으로 나옵니다.
- 마지막으로 **수정한 사람과 시각**이 줄에 표시되고, 수정 창에서 **수정 이력**을 볼 수 있습니다.
- 선생님이 여러 학생이 쓰는 교재를 고치면 "다른 선생님 학생을 포함해 ○명이 쓰고 있어요. 저장하면 모든 선생님 화면에 바로 반영돼요."라는 확인이 나옵니다.
- **삭제**: 아무도 쓰지 않는 교재만 삭제됩니다. 쓰는 학생이 있는 교재는 [선생님 권한](02-선생님-관리.md)의 "사용 중인 교재 삭제"를 켠 계정만 삭제할 수 있습니다.

## 4-2. 학생에게 교재 배정하기

1. 왼쪽 목록에서 학생을 눌러 학생 화면을 엽니다.
2. **교재 진도** 탭에서 **+ 교재 배정**을 누릅니다. (배정할 교재가 남아 있지 않으면 버튼이 비활성입니다)
3. 입력합니다.

| 항목 | 설명 |
|---|---|
| 교재 | 목록에서 고릅니다 |
| 현재 진도 | 이미 나간 단원 수. 새로 시작하면 0, 이미 7단원까지 했다면 7. **0.5 단위**로 넣을 수 있습니다 (예: 7.5) |
| 다음 교재 | 선택. 이 교재를 끝낸 뒤 이어서 할 교재 |
| 수업 요일 | 이 교재를 공부하는 요일(여러 개 가능). 비워 두면 모든 수업에서 쓸 수 있습니다 |
| 하루 추천 진도 범위 | 선택. 하루에 나갈 단원 수의 최소~최대. 수업 추천이 이 범위를 참고합니다 |

> **수업 기록은 그날의 요일에 배정된 교재만** 입력할 수 있습니다(요일 미지정 교재 포함). 다른 교재를 넣으려면 출결을 "보강"으로 바꿉니다. ([6장](06-수업-기록.md))

## 4-3. 교재 진도 탭 보는 법

📷 (교재 진도 탭)

교재마다 카드가 있고 다음이 나옵니다.

- **교재 이름**, 수업 요일 표시
- **하루 추천 진도 범위**와 최근 수업 평균 기반 추천 안내
- **현재 진도 / 전체 단원** (예: Unit 7 / 20)
- **최근 수업** 날짜와 진도 범위
- **진도 갱신** 날짜
- **다음 교재** (정해 둔 경우)

위쪽에서 **카드 / 요일별** 보기를 바꿀 수 있습니다. 요일별 보기는 월~일 열에 교재가 나뉘어 보이고, 교재를 누르면 요일을 바꿀 수 있습니다.

### 카드의 버튼

| 버튼 | 하는 일 |
|---|---|
| 교재 완료 | 이 교재를 끝낸 것으로 처리합니다. 수업 기록은 남고 **수업 추천에서는 빠집니다.** 다음 교재를 정해 두었으면 이어서 배정할지 묻습니다 |
| 요일 변경 | 수업 요일을 바꿉니다. 창 아래 **배정 해제**로 이 교재 배정을 끝낼 수도 있습니다 |
| 하루 추천 진도 범위 정하기/변경 | 하루에 나가는 분량의 범위를 정합니다. **범위 없애기**도 가능합니다 |
| 다음 교재 | 이 교재를 끝낸 뒤 이어서 할 교재를 정합니다 |
| 배정 해제 | 배정을 해제합니다. 수업 기록은 남지만 현재 진도·요일·다음 교재 설정은 초기화됩니다 |

### 진도는 어떻게 올라가나요?

**수업 기록을 저장할 때** 그 수업의 종료 단원으로 자동으로 올라갑니다. (결석은 제외, 학생 화면의 수업 기록 창에서는 체크를 끌 수 있습니다) 진도를 숫자로 직접 고치는 버튼은 없고, 필요하면 수업 기록에서 범위를 입력해 맞춥니다.

### 완료한 교재

교재를 완료하면 카드 아래 **완료한 교재** 목록으로 옮겨집니다.

- **완료 / 중간 종료** 표시와 날짜
- 수업 횟수, 시작~완료 기간
- **수업 기록 보기**: 그 교재의 수업 기록으로 이동
- **다시 진행**: 완료를 취소하고 진행 중으로 되돌림
- **접기 / 펼치기**로 목록을 숨길 수 있습니다.
