# 2. 선생님 관리

원장 1명과 선생님 여러 명이 같은 앱을 함께 쓸 수 있습니다. 이 메뉴는 **원장에게만** 보입니다.

**메뉴 위치:** 왼쪽 메뉴 맨 아래 **설정 → 선생님 관리**

## 선생님이 볼 수 있는 것, 없는 것

| 구분 | 원장 | 선생님 |
|---|---|---|
| 학생 | 전체 | **자기 담당 학생만** |
| 수업 기록·추천·월말평가서·결석 보강·라이팅·시험 | 전체 | 자기 담당 학생 것만 보고 수정 |
| 시간표 | 전체 | 내 학생만 보임 |
| 교재 | 전체 | 모든 선생님이 함께 사용 (추가·수정 가능) |
| 선생님 관리, 데이터 백업 | 가능 | 메뉴가 보이지 않음 |

> 이 제한은 화면에서만 가리는 것이 아니라 **데이터베이스가 직접** 막고 있어서, 다른 선생님 학생은 열어 볼 수도 없습니다.

## 선생님 추가하기

1. **선생님 관리** 화면 위쪽의 **+ 선생님 추가**를 누릅니다.
2. **이름**과 **이메일**을 입력하고 저장합니다.
3. 그 이메일로 **비밀번호 설정 메일**이 갑니다.
4. 선생님이 메일의 링크를 눌러 **비밀번호를 정하면** 로그인할 수 있습니다.
5. 처음에는 상태가 **초대 대기**이고, 선생님이 처음 로그인하면 **사용 중**으로 바뀝니다.

📷 (선생님 추가 창)

**메일이 오지 않을 때**
- 스팸함을 확인해 달라고 안내합니다.
- 선생님 줄의 **초대 다시 보내기**를 누르면 메일을 다시 보냅니다. (초대 대기 상태일 때만 보입니다)
- 이메일 주소가 틀렸다면 선생님 추가를 다시 해야 합니다.

## 선생님 목록 보는 법

한 줄에 선생님 한 명이 나오고 다음이 표시됩니다.

- **이름 / 이메일**
- **담당 학생 수**
- **상태**: 초대 대기 · 사용 중 · 중지
- **버튼**: 권한 / 초대 다시 보내기 / 이용 중지(또는 다시 사용)

## 권한 정하기

선생님 줄의 **권한**을 누르면 세 가지 항목을 켜고 끌 수 있습니다.

| 권한 | 켜면 |
|---|---|
| 타임 추가·삭제·시간 변경 | 시간표의 요일·타임 구조를 선생님이 바꿀 수 있음 |
| 사용 중인 교재 삭제 | 다른 학생이 쓰고 있는 교재도 삭제할 수 있음 |
| 새 학생 등록·퇴원 처리 | 학생을 직접 추가하고 퇴원·복귀 처리를 할 수 있음 |

**항상 가능한 것** (권한과 무관): 내 학생의 기록 입력, 시간표 보기와 내 학생 배정·해제, 교재 추가·수정

> 권한을 끄면 그 기능은 원장만 할 수 있습니다. 선생님이 새 학생을 직접 등록하게 하고 싶지 않으면 "새 학생 등록·퇴원 처리"를 꺼 두세요.

## 학생 배정하기

선생님 관리 화면 아래쪽에 학생 목록이 있습니다.

1. 위쪽 탭(**전체 / 원장 / 선생님 이름**)으로 보고 싶은 범위를 고릅니다.
2. 학생 줄에서 **담당 선생님**을 고릅니다. 선택하면 바로 저장됩니다.
3. 담당을 정하지 않은 학생은 **원장 담당**입니다.

📷 (학생 배정 화면)

- 담당을 바꾸면 **기록은 학생에게 그대로 따라갑니다.** 이전 선생님 화면에서는 그 학생이 사라지고, 새 선생님 화면에 나타납니다.
- 학생 한 명의 담당 선생님은 한 명입니다.

## 이용 중지 / 다시 사용

- **이용 중지**: 그 선생님의 로그인을 막습니다. 입력한 데이터는 그대로 남습니다.
- **다시 사용**: 중지를 풀면 바로 다시 로그인할 수 있습니다.
- 선생님이 그만두었을 때는 먼저 담당 학생을 다른 선생님이나 원장에게 옮긴 뒤 이용 중지하세요.

## 선생님별로 걸러 보기

원장 화면의 **전체 현황, 결석·보강, 월말평가서, 수업 추천, 수업 기록, 라이팅 분석** 위쪽에는 `담당 선생님 [전체] [원장] [선생님 이름]` 버튼이 나옵니다.

- **전체**: 모든 학생이 보입니다.
- **선생님 이름**: 그 선생님 학생만 보입니다. 선택은 여섯 화면이 함께 씁니다.
- 선생님 이름이 보이지 않으면 아직 선생님이 없거나 이용 중지 상태입니다.

📷 (담당 선생님 필터)

## 알아두기

- 원장 계정으로 입력하든 선생님 계정으로 입력하든 데이터의 주인은 **원장**입니다. 선생님을 바꿔도 데이터를 옮길 필요가 없습니다.
- 선생님 계정은 **비밀번호를 선생님 본인이** 정합니다. 원장이 비밀번호를 알려 줄 수는 없습니다.
- 교재를 마지막으로 수정한 사람과 시각은 교재 수정 창에서 볼 수 있습니다. ([4장](04-교재와-진도.md))
