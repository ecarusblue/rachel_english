# 7. 수업 추천

학생마다 **다음 수업에서 나갈 교재와 단원 범위**를 미리 제안해 주는 화면입니다.
추천은 두 가지 방법으로 생깁니다.

- **자동 추천**: Claude 예약 작업이 학생의 현재 진도와 최근 수업을 보고 만들어 둡니다.
- **직접 입력**: 선생님·원장이 학생 화면에서 직접 추천을 적습니다.

추천은 **참고용 제안**입니다. 그대로 쓰거나, 고치거나, 거절할 수 있고, 어느 쪽이든 기록이 남습니다.

> 자동 추천 예약 작업의 설정은 `docs/recommend-api.md`에 있습니다. 이 매뉴얼은 화면 사용법만 다룹니다.

## 7-1. 전체 수업 추천 화면

**메뉴 위치:** 왼쪽 메뉴 **수업 추천**

📷 (수업 추천 화면 전체)

### 화면 구성

- **제목 줄**: `이번 주 ○/○ ~ ○/○` 기간이 표시됩니다. 이번 주 수업 예정인 추천만 모아서 보여 줍니다.
- **담당 선생님 버튼** (원장 화면): `전체 / 원장 / 선생님 이름`. 선생님을 고르면 그 선생님 학생의 추천만 보입니다.
- **보기 방식**: `날짜별` / `학생별`. 선택한 방식은 기억됩니다.

### 날짜별 보기

수업 예정일이 가까운 순서로 표가 나옵니다.

| 열 | 보이는 내용 |
|---|---|
| 학생 | 학생 이름 |
| 추천 교재 · 범위 | 교재 이름과 추천 단원. 아래 작은 글씨로 **현재 진도**가 같이 나옵니다. |
| 수업 예정일 | 추천이 대상으로 하는 수업 날짜. 이미 수업 기록이 있으면 기록 칩이 함께 보입니다. |
| 근거 | 이 범위를 추천한 이유 |
| 상태 | `제안` / `채택` / `수정` / `거절` 중 하나 + 버튼 |

표는 두 덩어리로 나뉩니다.

1. **수업 기록 없음** — 아직 그날 수업을 기록하지 않은 추천. 지금 처리할 것들입니다.
2. **수업 기록 있음** — 이미 수업 기록이 있는 날의 추천. `접기/펼치기` 버튼으로 숨길 수 있습니다.

같은 학생이 같은 날 교재를 여러 개 추천받았으면 한 묶음으로 보입니다.

### 학생별 보기

왼쪽에 학생 목록, 오른쪽에 선택한 학생의 추천이 날짜별 카드로 나옵니다.
위쪽 `‹ ›` 버튼으로 이전·다음 학생으로 넘어갈 수 있고, `전체 학생 ○명 보기` 버튼을 누르면 학생 목록 창이 열려, 이름으로 찾거나 처리할 추천이 있는 학생만 걸러 볼 수 있습니다.
카드 하나는 수업 하루이고, 그 안에 교재별 추천이 있습니다.

### 상태의 뜻

| 상태 | 의미 |
|---|---|
| **제안** | 아직 결정하지 않은 추천 (노란색 표시) |
| **채택** | 추천 그대로 수업 기록에 저장됨 |
| **수정** | 추천을 고쳐서 수업 기록에 저장됨 |
| **거절** | 쓰지 않기로 함 |

## 7-2. 추천을 수업 기록에 반영하기

가장 자주 하는 작업입니다.

1. 수업 추천 화면에서 학생 추천 줄의 **반영**(또는 **수업 기록 반영**)을 누릅니다.
   같은 날 추천이 여러 개면 **○개 모두 반영**이 나옵니다.
2. 수업 기록 창이 열리고 **추천 교재와 단원이 미리 채워져** 있습니다.
3. 출결·학습내용·숙제 등 나머지를 입력하고 저장합니다.
4. 추천 상태가 바뀝니다.
   - 추천과 **같게** 저장하면 → **채택**
   - 단원 등을 **바꿔서** 저장하면 → **수정**

수업 기록 화면(6장)의 **추천 단원으로 채우기** 버튼도 같은 추천을 사용합니다.

## 7-3. 추천 범위 고치기 (수업 추천 수정)

추천이 마음에 들지 않을 때, 수업 기록을 쓰기 전에 **추천 자체를 먼저 고칠** 수 있습니다.

1. 학생 화면의 **수업 추천** 탭을 엽니다. (수업 추천 화면의 학생별 보기에서도 같은 카드가 보입니다.)
2. 고치고 싶은 날짜 묶음의 **추천 수정**(또는 교재 줄의 **범위 수정**)을 누릅니다.
3. 교재마다 **시작 단원**, **끝 단원**을 바꿉니다. 단원이 정리된 교재는 목록(▼)에서 고르고, 일반 교재는 ±0.5 버튼이나 숫자로 입력합니다.
4. **추천 이유**를 고칩니다. 예: `학교 시험 2주 전이라 문법 위주로`
5. 저장합니다.

알아 둘 점:

- **상태가 `제안`인 추천만** 고칠 수 있습니다.
- **그날 수업 기록이 이미 있으면 고칠 수 없습니다.** 버튼이 잠금 표시로 바뀝니다.
- 직접 고친 추천에는 수정 표시가 남아, **다음에 자동 추천이 돌아도 덮어쓰지 않습니다.**

## 7-4. 추천 직접 입력하기

자동 추천이 없거나, 특정 날짜에 원하는 범위를 직접 정하고 싶을 때 씁니다.

1. 학생 화면 → **수업 추천** 탭 → 오른쪽 위 **＋ 추천 직접 입력**.
2. **수업 날짜**를 고릅니다. 그 학생의 수업 요일 중 가까운 날짜가 버튼으로 나옵니다.
3. 교재를 고르고 **시작 단원 / 끝 단원**을 정합니다. 교재 아래에 `현재 진도`가 보여 참고할 수 있습니다.
   교재를 더 넣으려면 **＋ 교재 추가**를 누릅니다.
4. **메모 / 근거**(선택)를 적습니다.
5. 저장하면 `제안` 상태로 등록됩니다. 이후는 자동 추천과 똑같이 반영·수정·거절을 쓸 수 있습니다.

같은 날 같은 교재에 이미 제안이 있으면 저장되지 않고 "이미 제안이 있어요"라는 안내가 나옵니다. 그때는 기존 추천을 **추천 수정**으로 고치세요.

## 7-5. 추천 거절하기

1. **거절**을 누릅니다. 같은 날 교재가 여러 개이면 `이 교재만 거절` 또는 `모두 거절`을 고릅니다.
2. 확인 창에서 확인하면 상태가 **거절**로 바뀝니다.

거절한 추천은 목록에서 빠지고, 수업 기록 채우기에도 쓰이지 않습니다. 수업 기록이 이미 있는 날에는 거절할 수 없습니다.

## 7-6. 학생 화면의 수업 추천 탭

학생 한 명의 추천을 **기간별**로 모아 봅니다.

- 맨 위 **기간** 선택칸(전체 기간·이번 주·지난 주·다음 주·이번 달·지난 달·직접 선택)과 시작일·종료일로 범위를 바꿔 지난 추천을 볼 수 있습니다.
- 같은 줄의 **인쇄 / PDF 저장** 버튼으로 그 기간의 추천을 인쇄할 수 있습니다.
- 아직 처리하지 않은 추천이 위에, **지난 추천**(채택·수정·거절)이 아래에 나옵니다.
- 날짜 카드마다 요일, 교재 수, 수업 기록 유무가 표시됩니다.

## 7-7. 미리보기·인쇄

수업 추천 화면의 인쇄 버튼으로 **날짜별 추천표**를 A4 인쇄 화면으로 미리 볼 수 있습니다.
담당 선생님 필터를 켠 상태라면 제목에 선생님 이름이 함께 나오고, 그 선생님 학생만 인쇄됩니다.

## 7-8. 선생님 계정에서는

- 선생님은 **자기 담당 학생의 추천만** 보고 고치고 거절할 수 있습니다.
- 원장은 전체를 다룹니다.
