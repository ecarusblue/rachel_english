# Rachel English 진도표 · 사용자 매뉴얼 (원장용)

처음 쓰시는 원장님이 **따라 하면서 익힐 수 있도록** 화면 순서대로 정리한 안내서입니다.
각 장은 "무엇을 하는 화면인지 → 어떻게 쓰는지 → 화면에 나오는 데이터가 무슨 뜻인지" 순서로 되어 있습니다.

> 이 매뉴얼은 **원장 계정** 기준입니다. 선생님 계정은 같은 화면을 쓰지만 자기 담당 학생만 보이고, 일부 메뉴(선생님 관리, 데이터 백업)는 보이지 않습니다. 선생님용 매뉴얼은 별도로 만들 예정입니다.

## 처음 시작하는 순서 (권장)

1. [로그인](01-시작하기.md)하고 비밀번호를 바꿉니다.
2. [교재 관리](04-교재와-진도.md)에서 쓰는 교재를 먼저 만듭니다.
3. [시험종류입력](10-시험-단어.md)에서 시험 종류를 확인합니다. (기본 종류가 이미 있습니다)
4. [학생을 추가](03-학생-관리.md)하고 교재를 배정합니다.
5. [수업 시간표](05-수업-시간표.md)를 만들고 학생을 배정합니다.
6. 선생님이 있다면 [선생님을 추가](02-선생님-관리.md)하고 학생을 나눠 맡깁니다.
7. 수업이 끝날 때마다 [수업 기록](06-수업-기록.md)을 입력합니다.

## 용어 모음

| 용어 | 뜻 |
|---|---|
| 원장 | 모든 학생·기록·설정을 볼 수 있는 관리자 계정 |
| 담당 선생님 | 학생마다 한 명씩 정해 두는 선생님. 정하지 않으면 원장 담당 |
| 교재 배정 | 학생에게 그 교재를 쓰기 시작한다고 등록하는 것 |
| 현재 진도 | 그 교재에서 지금까지 나간 단원 수 (예: 7이면 Unit 7까지 완료) |
| 타임 | 시간표의 한 수업 시간대 (예: 월요일 4시 타임) |
| 출결 | 출석 / 지각 / 결석 / 보강 중 하나 |
| 보강 | 결석한 수업을 다른 날 채우는 것 |
| 추천 | 학생별 다음 수업에 할 교재·단원을 제안한 것 |
