# 8. 월말평가서

한 달 동안의 수업 기록을 바탕으로 **학생별 평가서**를 만들고 학부모에게 전달하는 화면입니다.
수업·출석·숙제·시험 숫자는 **수업 기록에서 자동으로 집계**되고, 선생님은 평가와 서술 문장만 채우면 됩니다.

평가서 초안은 Claude 예약 작업이 미리 써 둘 수도 있습니다(`AI 초안`). 그 설정은 `docs/evaluation-api.md`를 참고하세요.

**메뉴 위치:** 왼쪽 메뉴 **월말평가서**

## 8-1. 학생 목록 화면

📷 (월말평가서 목록 화면)

### 화면 구성

- **연도 / 월** 선택칸: 평가서를 쓸 달을 고릅니다. 기본은 이번 달입니다.
- **담당 선생님 버튼** (원장 화면): `전체 / 원장 / 선생님 이름`. 고른 선생님의 학생만 목록에 나오고, 작성 현황 숫자도 그 학생들 기준으로 바뀝니다.
- **작성 현황**: `○명 중 ○명 완료`와 진행 막대
- **학생 표**: 재원 중인 학생만 나옵니다. 줄을 누르면 그 학생의 평가서 화면으로 들어갑니다.

### 표의 열

| 열 | 어떻게 계산되나요 |
|---|---|
| 수업 | 그 달 수업 기록 개수 |
| 출석률 | 수업 기록 중 출석한 비율 (출석·지각·보강을 출석으로 셉니다) |
| 숙제 완료율 | 숙제 결과 중 **완료**의 비율 (완료 / 완료+일부+미제출) |
| 시험 평균 | 그 달에 기록된 시험 점수의 평균 |
| 평가서 | 상태 표시 (아래 참고) |

숫자가 `-`이면 그 달에 해당 기록이 없다는 뜻입니다.

### 평가서 열의 표시

| 표시 | 의미 |
|---|---|
| **작성하기** (파란 버튼 모양) | 수업 기록은 있는데 평가서는 아직 없음 |
| 수업 기록 없음 | 그 달 수업 기록이 없어 작성할 근거가 없음 |
| 임시저장 | 임시로 저장한 상태 |
| 작성 중 | 쓰는 중 |
| AI 초안 | Claude가 써 둔 초안. 확인·수정이 필요 |
| 완료 | 확정한 평가서 |

## 8-2. 평가서 작성·수정하기

학생 줄을 누르면 평가서 화면이 열립니다.

📷 (평가서 작성 화면)

### 위쪽: 자동 집계 (고칠 수 없는 참고 자료)

수업 기록에서 모은 내용이 먼저 보입니다.

- 수업 횟수와 출석·지각·결석·보강 횟수
- 숙제 결과
- 시험 평균과 지난달 대비 변화
- **이번 달 진도**: 교재별 진행 범위와 현재 위치
- **수업 코멘트**: 이번 달 수업 기록에 적은 코멘트들
- **시험 점수 추이**: 최근 3개월

> 이 내용을 바꾸려면 평가서가 아니라 **수업 기록**을 고쳐야 합니다.

### 아래쪽: 직접 쓰는 부분

1. **영역별 평가**: 듣기·말하기·읽기·쓰기·어휘·문법을 각각 5단계로 고릅니다.
   `매우 우수 / 우수 / 보통 / 노력 필요 / 많이 노력 필요`
2. **학습 태도**: 참여도·집중도·숙제 성실도를 같은 5단계로 고릅니다.
3. **서술 4칸** (각 3,000자까지)
   - 이달의 성취
   - 보완할 점
   - 다음 달 학습 계획
   - 학부모께 드리는 말씀
4. **상태**를 고릅니다.
   - 쓰다 만 경우: `임시저장` 또는 `작성 중`
   - 확정할 경우: `완료`
5. **저장**을 누릅니다. "저장했습니다"라는 안내가 나오고 목록으로 돌아갑니다.

`← 학생 목록` 버튼으로 목록으로 돌아갈 수 있습니다. 저장하지 않은 내용은 사라집니다.

### AI 초안을 받았을 때

화면 위에 "AI 초안 — Claude가 작성했습니다"라는 안내가 나옵니다.

1. 내용을 읽고 어색한 부분을 고칩니다.
2. 상태를 **작성 중** 또는 **완료**로 바꿔 저장합니다.

⚠️ **상태를 `AI 초안`이나 `임시저장`으로 두면 다음 예약 작업이 내용을 다시 씁니다.** 직접 고친 내용을 지키려면 반드시 `작성 중`이나 `완료`로 저장하세요.

## 8-3. 미리보기와 인쇄

평가서 화면 아래 **평가서 미리보기**를 누르면 A4 모양의 평가서를 먼저 볼 수 있습니다.

- **인쇄 / PDF 저장**: 인쇄하거나 PDF 파일로 저장합니다.
- 내용이 길면 두 장 이상으로 나뉘며, 미리보기 아래에 "○장으로 인쇄됩니다"라고 안내됩니다.
- 모바일에서는 공유 기능으로 PDF 파일을 바로 보낼 수 있습니다. 파일 이름은 `월말평가서_학생이름_2026-10.pdf` 형식입니다.

미리보기는 **현재 화면에 입력한 내용** 기준입니다. 저장하지 않았더라도 미리보기에는 반영됩니다. 다만 저장해야 다음에 다시 볼 수 있습니다.

## 8-4. 이렇게 쓰시면 편해요

1. 달이 끝나면 **월말평가서**를 열고 연도·월을 확인합니다.
2. 표에서 `수업 기록 없음`이 아닌 학생 순서대로 들어갑니다.
3. 자동 집계와 수업 코멘트를 읽고 평가를 고릅니다.
4. 서술 칸을 채우고 `완료`로 저장합니다.
5. 작성 현황이 `○명 중 ○명 완료`로 다 찰 때까지 반복합니다.
6. 학부모에게 보낼 학생은 미리보기에서 PDF로 저장합니다.

## 8-5. 선생님 계정에서는

- 선생님은 **자기 담당 학생의 평가서만** 보이고 쓸 수 있습니다.
- 원장은 전체 학생을 다루며, 담당 선생님 버튼으로 선생님별로 모아 볼 수 있습니다.
