# 10. 시험·단어

단어시험, 단원평가, 모의고사 같은 **시험 점수**를 기록하고 점수 변화를 보는 기능입니다.
점수는 두 곳에서 입력할 수 있습니다.

| 입력 위치 | 언제 쓰나요 |
|---|---|
| **수업 기록** 화면의 학생 카드 (6장) | 그날 수업 때 본 시험을 수업 기록과 함께 입력 |
| **학생 화면 → 시험·단어 탭** (이 장) | 시험 점수만 따로 입력·수정하거나 한꺼번에 업로드 |

입력한 점수는 **전체 현황의 시험 평균**, **월말평가서의 시험 평균과 추이**에 자동으로 반영됩니다.

## 10-1. 시험 종류 정하기 (처음 한 번)

점수를 입력할 때 고르는 **종류** 목록을 먼저 정해 둡니다. 모든 학생이 같은 목록을 씁니다.

**메뉴 위치:** 왼쪽 메뉴 아래쪽 **시험종류입력**

📷 (시험 종류 화면)

처음에는 `단어시험`, `단원평가`, `모의고사`, `기타`가 기본으로 들어 있습니다.

### 종류 추가·수정

1. **+ 종류 추가**를 누릅니다. (기존 종류는 줄을 눌러 수정)
2. 아래 항목을 입력합니다.

| 칸 | 설명 |
|---|---|
| 종류 이름 | 예: `Unit 테스트`, `듣기평가` |
| 기본 만점 | 점수를 입력할 때 만점 칸에 자동으로 들어가는 값 |
| 단위 | 점, 개 등 자유롭게. 자주 쓰는 단위는 버튼으로 고를 수 있습니다. |
| 그래프 색 | 점수 추이 그래프에서 이 종류를 나타내는 색 |
| 메모 (선택) | 예: 단어 30개 중 맞힌 개수 |

3. 저장합니다.

목록의 각 줄에는 `기본 만점 ○점 · 기록 ○건`이 함께 나옵니다. 종류가 많으면 위쪽 검색칸에서 이름으로 찾을 수 있습니다.

알아 둘 점:

- **단위가 달라도 그래프는 항상 백분율(%)** 로 보여 줍니다. 그래서 `30개 중 27개`와 `100점 중 90점`을 같은 그래프에서 비교할 수 있습니다.
- `기본 종류` 표시가 붙은 종류는 단위·만점을 **처음 설정(점, 100)으로 되돌릴** 수 있습니다.
- **점수 기록이 있는 종류는 삭제할 수 없습니다.** ("기록이 있는 종류는 삭제할 수 없어요" 안내) 쓰지 않는 종류만 삭제하세요.

## 10-2. 학생 화면의 시험·단어 탭

**메뉴 위치:** 왼쪽 학생 목록에서 학생 선택 → **시험·단어** 탭

📷 (시험·단어 탭)

### 점수 하나 입력하기

1. **+ 시험 점수**를 누릅니다.
2. 입력합니다.

| 칸 | 설명 |
|---|---|
| 날짜 | 시험 본 날 (기본값은 오늘) |
| 종류 | 10-1에서 만든 종류 중 선택. 고르면 **만점이 기본값으로 자동 입력**되고, 점수 칸 이름에 단위가 표시됩니다. |
| 시험 이름 | 선택. 예: `Unit 5 단어` |
| 점수 | 받은 점수 |
| 만점 | 시험의 만점 (필요하면 고칩니다) |

3. 저장합니다. **점수가 만점보다 크면** "점수가 만점보다 클 수 없습니다"라고 안내되고 저장되지 않습니다.

### 수정·삭제

표에서 시험 줄을 누르면 수정 창이 열립니다. 여기서 값을 고치거나 **삭제**할 수 있습니다.

### 화면에서 보이는 데이터

- **추이 카드·그래프**: 시험 종류별 점수 변화 (백분율)
- **기간** 선택칸: 전체 기간·이번 주·이번 달·직접 선택 등으로 범위를 좁혀 볼 수 있습니다.
- **요약 카드 4개**

| 카드 | 의미 |
|---|---|
| 전체 평균 (기간을 고르면 기간 평균) | 보이는 시험들의 평균 백분율 |
| 최근 ○회 평균 | 가장 최근 시험 5회의 평균 |
| 최고 | 가장 높은 백분율 |
| ○회 | 시험 횟수 |

- **시험 표**: 날짜, 종류, 이름, 점수(`27/30개`처럼), 백분율

## 10-3. 엑셀로 한꺼번에 올리기

지난 시험 기록이 엑셀에 있거나 한 번에 많이 넣을 때 편합니다. 학생 한 명 단위로 합니다.

1. 학생의 **시험·단어** 탭에서 **양식 다운로드**를 누릅니다.
   내려받은 파일에는 **종류 목록**이 들어 있어 종류 칸에서 고를 수 있습니다.
2. 엑셀의 **[점수입력] 시트**에 시험을 **한 줄에 한 건**씩 적습니다.

| 열 | 내용 |
|---|---|
| 날짜 | `2026-10-21` 형식 (엑셀 날짜 칸도 가능) |
| 종류 | 시험 종류 |
| 시험 이름 | 선택 |
| 점수 | 받은 점수 |
| 만점 | 시험 만점 |
| 구분 | 맨 위 회색 **예시** 줄 표시용. 직접 쓸 필요 없습니다. |

3. **엑셀 업로드** 버튼으로 파일을 올리면 확인 창이 열립니다.
4. 내용을 확인하고 저장합니다.

맨 위 회색 **예시 줄은 업로드할 때 무시**됩니다. 지우지 않아도 됩니다.

## 10-4. 선생님 계정에서는

- 선생님은 **자기 담당 학생의** 시험 점수를 입력·수정할 수 있습니다.
- **시험 종류 관리**는 모든 학생이 함께 쓰는 설정이므로, 바꾸면 전체에 영향이 있습니다. 필요한 종류는 원장이 한 번에 정해 두는 것을 권장합니다.
